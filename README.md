# 설문 집계기

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 단일 페이지입니다.

**바로 쓰기: https://fmlm66.github.io/survey-tally/**

- `index.html` 파일 하나로 동작합니다. 위 주소(GitHub Pages, `main` 브랜치 맨 위 폴더에서 배포)로 쓰거나, 내려받아 브라우저로 열어도 됩니다.
- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않고, 붙여넣은 데이터는 브라우저 밖으로 보내거나 저장하지 않습니다(CSP로 외부 연결 차단).

## 집계 규칙

- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`~`5`면 유효, 비었거나 공백뿐이면 빈 응답, 그 밖의 값은 제외입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 보이며, 유효 응답이 없으면 `-`입니다.

세부 결정(끝의 빈 줄, 엑셀 따옴표 칸 등)은 [PLAN.md](PLAN.md)에 있습니다.

## 시험

Node 18 이상이 필요하며 설치할 의존성은 없습니다.

```bash
npm test
```

- `tests/tally.test.mjs`: `index.html`의 `<script id="tally-core">`(계산 로직)만 뽑아 실행해 집계 규칙을 확인합니다.
- `tests/page.test.mjs`: 외부 주소·네트워크 호출·저장소 사용이 없는지, CSP와 `.nojekyll`이 있는지 확인합니다.
