# 아침 뉴스 요약 계획서

## 목표

매일 아침, 정해 둔 주제에 관한 뉴스를 지정한 신문사·방송사에서 골라 짧게 요약한 웹페이지를 만든다.

## 정한 것

| 항목 | 결정 |
| --- | --- |
| 기존 설문 집계기 | 그대로 둔다. 새 프로그램은 `news-digest/`, 결과 페이지는 `news/` 폴더 |
| 받아 보는 곳 | GitHub Pages 웹페이지: `https://fmlm66.github.io/survey-tally/news/` |
| 실행 | GitHub Actions가 매일 06:40(한국 시각)에 실행. GitHub 사정으로 몇 분~수십 분 늦을 수 있음 |
| 선별·요약 | 외부 API 없이 키워드로 고르고, 언론사가 RSS에 실어 주는 기사 요약문의 앞 두 문장을 보여 준다 |
| 주제·언론사 | `news-digest/config.json`에서 바꾼다. 처음 값은 주제 "AI(인공지능)", RSS를 제공하는 국내 언론사들 |
| 언어·의존성 | Python 표준 라이브러리만 사용(설치할 것 없음) |

## 기사 수집

- 각 언론사의 공식 RSS(또는 Atom) 주소에서만 가져온다. 기사 본문 페이지는 긁어 오지 않는다(사이트마다 구조가 달라 쉽게 깨지고, 저작권 부담도 크다).
- 한 언론사 주소가 실패해도 나머지로 페이지를 만든다. 실패한 곳은 페이지 아래에 적는다. 모두 실패하면 실행을 실패로 끝낸다.
- EUC-KR 등 XML에 적힌 인코딩을 따른다. 맨 `&`처럼 흔한 XML 오류는 고쳐서 다시 읽는다.

## 선별 규칙

1. **기간**: 실행 시각 기준 최근 `window_hours`(기본 24시간) 안에 나온 기사. 날짜가 없는 기사는 오래된 것일 수 있어 뺀다.
2. **주제 판정**: 키워드가 제목에 있으면 3점, 요약문에 있으면 1점(키워드마다). 0점이면 뺀다. 영문 키워드(`AI` 등)는 영문 단어 안에 묻힌 경우(`MAIN`, `Thailand`)를 세지 않는다. 제외 키워드가 있으면 뺀다.
3. **중복 묶기**: 주소가 같으면 하나로. 제목이 비슷하면(글자 2개 단위 겹침 비율 0.5 이상) 같은 소식으로 묶고, 대표 기사 하나에 "같은 소식: 다른 언론사들"을 붙인다.
4. **순위**: 여러 언론사가 다룬 소식 → 점수 → 최신 순. 전체 `max_articles`(기본 15)개, 한 언론사에서 최대 `per_source_max`(기본 5)개.

## 요약

- RSS 요약문에서 HTML 태그·특수문자 표기를 지우고, 앞머리의 `(서울=연합뉴스) 홍길동 기자 =` 같은 기자 표기와 `[사진]` 같은 머리표를 걷어 낸다.
- 앞 두 문장, 최대 200자. 더 길면 `…`로 자른다. 요약문이 없으면 제목만 보인다.
- 원문 링크를 꼭 단다.

## 결과 페이지

- `news/YYYY-MM-DD.html`(한국 날짜): 그날 요약. `news/index.html`: 가장 최근 요약과 지난 날짜 목록.
- 외부 스크립트·글꼴·분석 도구 없음. CSP로 외부 불러오기를 막는다(기사 링크를 누르는 것은 됨). 휴대폰 화면, 어두운 모드 지원.
- 고른 기사가 없으면 "해당 주제의 새 기사가 없습니다"라고 적는다.

## 구조

```
news-digest/
  config.json          주제·키워드·언론사·개수
  newsdigest/
    feeds.py           RSS/Atom 읽기, 날짜 읽기, 내려받기
    select.py          키워드 점수, 기간, 중복 묶기, 순위
    summarize.py       요약문 다듬기
    render.py          HTML 만들기
    __main__.py        실행: python -m newsdigest (--check-feeds)
  tests/               unittest + 예시 RSS 파일
news/                  매일 만들어지는 결과(Actions가 커밋)
.github/workflows/
  news-digest.yml       매일 실행 → news/ 커밋 → Pages 갱신
  news-digest-test.yml  PR마다 시험 + RSS 주소 점검
```

## 시험

- `cd news-digest && python -m unittest`: 인터넷 없이 예시 파일로 읽기·선별·요약·페이지 만들기를 시험한다.
- `python -m newsdigest --check-feeds`: 각 RSS 주소가 열리고 기사가 몇 개 나오는지 보고한다. 이 세션에서는 언론사 접속이 막혀 있어 PR CI에서 돌려 확인한다.

## 작업 순서(작업마다 커밋)

1. 계획서
2. RSS 읽기 + 시험
3. 선별·요약 + 시험
4. 페이지 만들기·실행 명령 + 시험
5. 설정 파일, README, 시험 CI(+RSS 점검)
6. 매일 실행 워크플로
