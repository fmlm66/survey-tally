# 아침 뉴스 요약

매일 아침, 주제별로 지정한 신문사·방송사 기사 가운데 **중요하면서 읽을 가치가 있는 기사 5건**씩을 골라 짧은 요약 페이지로 만듭니다. 주제는 페이지 위쪽 탭으로 나눠 봅니다.

- 보는 곳: https://fmlm66.github.io/survey-tally/news/ (지난 요약도 같은 페이지 아래에 있습니다)
- 탭(8개): 국내정치, 세계정치, 산업경제, 금융증권, 사회, 문화, 과학기술, 해외 언론(New York Times·BBC News, 영어 원문)
- 실행: GitHub Actions가 매일 06:40(한국 시각)에 돌립니다. GitHub 사정으로 몇 분~수십 분 늦을 수 있습니다. Actions 탭의 **news-digest daily** → **Run workflow**로 바로 돌릴 수도 있습니다.
- 외부 API·유료 서비스 없이 Python 표준 라이브러리만 씁니다.

## 고르는 방법

기사마다 **점수 = 중요도 + 읽을 가치 − 감점**을 매겨 높은 순으로 주제마다 5건을 고릅니다.

| 구분 | 신호 | 점수(기본) |
| --- | --- | --- |
| 중요도 | 같은 소식을 보도한 다른 언론사 1곳마다 | +3 (최대 +12) |
| | 언론사 주요뉴스(SBS·NYT·BBC 첫 화면 RSS)에 실림 | +3 |
| | 후속 보도 "(종합)", "(2보)" | +1 |
| 읽을 가치 | [단독]·[심층]·[기획]·[분석]·[탐사]·[팩트체크]·[인터뷰] | +3 |
| | 본문 길이 600자 이상 / 1,500자 이상 | +1 / +2 |
| | 요약문에 수치·인용 | +1 |
| 감점 | 보도자료·홍보성(맞손, MOU, 출시, 선정, 수상, 개최 …) | −4 |
| | 연예·가십·연재물(열애, 근황, 음주운전, [n화] …) | −4 |
| 제외 | [속보]·[표]·[인사]·[부음]·운세·로또·날씨·브리핑, 본문 300자 미만 | - |

- **같은 소식**: 제목이 비슷하거나 핵심 낱말이 3개 이상 겹치면 한 소식으로 묶고(묶음 구성원 과반과 같아야 들어감), 뽑힌 뒤에도 제목+요약문 낱말이 많이 겹치면 한 번 더 합칩니다. 한 항목만 보이고, 다른 언론사 기사는 "같은 소식 다른 기사" 링크로 붙습니다.
- **한 주제에만**: 한 소식은 기사가 가장 많이 실린 주제 하나에만 나옵니다.
- **다양성**: 한 언론사는 주제마다 2건(해외 언론 탭은 3건), 칼럼 등 의견 기사는 1건까지.
- **본문 재기**: 주제마다 점수가 높은 기사부터 최대 60건의 기사 페이지를 열어 본문 글자 수를 셉니다. 기사 본문은 글자 수만 세고 저장하거나 보여 주지 않습니다(해외 언론 탭은 유료벽 때문에 본문을 못 읽어도 후보에 남깁니다).
- **요약**: 언론사가 RSS(없으면 기사 페이지 소개문)에 실은 글의 앞 두 문장(최대 200자). 기자 표기와 되풀이한 제목은 걷어 냅니다. 전체 내용은 원문 링크에서 보세요.

## 주제·언론사 바꾸기

`config.json`을 고칩니다.

| 항목 | 뜻 |
| --- | --- |
| `title` | 페이지 제목 |
| `topics` | 주제 목록(탭 순서). 주제마다 `name`과 `feeds`(`source` 언론사 이름, `url` RSS 주소). 주제별로 `per_source_max`, `body_optional`(본문 못 읽어도 후보)을 따로 줄 수 있습니다 |
| `headline_feeds` | 언론사 주요뉴스(첫 화면) RSS. 여기 실린 기사에 주요뉴스 점수를 줍니다 |
| `exclude_titles` | 제목이 이 정규식에 맞으면 뺍니다(운세, [속보] 등) |
| `scoring` | 점수와 단어 목록 바꾸기. 예: `{"headline": 5}`. 빠진 항목은 `newsdigest/scoring.py`의 기본값 |
| `per_topic` | 주제마다 보일 기사 수(기본 5) |
| `max_fetch_per_topic` | 주제마다 본문 길이를 잴 최대 기사 수(기본 60). 늘리면 정확해지지만 느려지고 언론사 사이트 부담이 커집니다 |
| `window_hours` | 최근 몇 시간 안의 기사만 볼지(기본 24) |
| `sources` | 언론사별 선택 설정. `"undated": "recent"`는 날짜를 싣지 않는 RSS의 기사를 최근 기사로 봅니다 |

RSS 주소를 바꾼 뒤에는 아래 점검을 돌려 기사와 본문이 읽히는지 확인하세요.

## 직접 돌리기·점검·시험

```bash
cd news-digest
```

```bash
python -m newsdigest --check-feeds
```

```bash
python -m newsdigest --out ../news --print
```

```bash
python -m unittest -v
```

- `--check-feeds`: 주제·언론사별로 RSS가 열리는지, 최근 기사 수, 첫 기사 페이지의 본문 글자 수를 표로 보여 줍니다.
- `--now 2026-11-18T16:30:00+09:00`: 기준 시각을 정해 만듭니다.
- `--dump 파일` / `--from-dump 파일`: 수집·측정 결과를 저장했다가 접속 없이 다시 만듭니다.
- GitHub Actions의 **news-digest test** 워크플로가 PR마다(또는 Run workflow로) 시험, RSS·본문 점검, 미리보기를 돌립니다.
